The project you build

The whole course is one project: an Airbnb analytics pipeline on Snowflake. Three raw tables land in a RAW schema, and by the end you have staging models, cleansed dimensions, an incremental fact table, a seed, two snapshots, a mart, tests, contracts, documentation and a dashboard exposure — deployed through a CI pipeline.

Alongside the DAG the course also builds two snapshots over the raw sources, a seed_full_moon_dates seed, singular and generic tests, a unit test, a contract on dim_hosts_cleansed, and three Python models.

Everyday analogy — dbt is a build tool for SQL, in the same sense that Make is a build tool for C. You write the recipes; dbt works out the order, runs what needs running, and refuses to carry on when a step fails its checks.

The certification this maps to

The course is aligned to the dbt Analytics Engineering Certification. The exam publishes eight topic areas but no percentage weightings — every question is worth one point and all are weighted equally, so there is no domain worth cramming over another.

Question formats to expect. The exam is not only multiple choice. It also uses fill-in-the-blank, matching, hotspot, build-list and Discrete Option Multiple Choice questions, so recognising a config key is not enough — you have to be able to write it. Rebuilding the site

The search index and the curriculum block above are generated. After editing any page:

python build_site.py        # search index + curriculum block
python validate_site.py     # links, anchors, code blocks, Jinja balance
python tools/audit_site.py  # unknown CSS classes and content inventory
node tools/highlight_smoke.js   # syntax highlighter
python tools/validator_smoke.py # the validator's own checks

Those prove the HTML is sound. A second set asks whether the writing is trustworthy — whether the code we claim to quote is really the code in the course repo, whether anything the instructor demonstrates is missing, and whether the prose has drifted into filler:

python tools/quality_audit.py        # quoted code vs the real repo files
python tools/transcript_coverage.py  # every command and model in the lesson script
python tools/prose_audit.py          # self-corrections, filler, placeholders
python tools/title_consistency.py    # hub cards, h1s and pager labels agree
python tools/lecture_count.py        # lecture totals match what the hub claims
python tools/coverage_probe.py       # certification vocabulary
node tools/search_smoke.js           # the search finds what a reader types
